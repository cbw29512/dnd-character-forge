Character Forge

Privacy

Character Forge is designed to work without an account or hosted character database.

What stays in your browser

Saved Pregens, Homebrew records, and saved presentation data are stored in your browser's local storage. They remain on that browser profile unless you remove them, clear site data, or import/export them yourself.

Backup files

Pregen backup export creates a file only when you request it. Backup import reads a file you choose in the browser so the local Pregen library can be restored.

Analytics and telemetry

The Character Forge application does not include an analytics or telemetry client and does not send saved character-library data to a Character Forge application server.

External links

Character Forge may include ordinary external links, such as a support link. Leaving Character Forge is subject to the destination site's own privacy practices.

If future releases add accounts, hosted storage, analytics, payments, or other data-processing services, this disclosure must be updated before those features are treated as production-ready.
