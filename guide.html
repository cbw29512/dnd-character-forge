D&D 5e pregen guide

From choices to a ready-to-play character.

Character Forge is built for the moment when you need a playable D&D 5e character without manually assembling every supported rule choice. Pick what matters, leave the rest Random, validate the result, then save or print it.

Source boundary: Character Forge supports its verified 2014 SRD 5.1 and 2024 SRD 5.2.1 rules surfaces plus clearly labeled Character Forge Original options. Unsupported content stays unavailable rather than being guessed.

How to generate a pregen

1

Choose the rules edition

Select 2014 · SRD 5.1 or 2024 · SRD 5.2.1. Character Forge keeps edition-specific mechanics isolated throughout the generated character.

2

Pick only what matters

Set a level, class, species, subclass, background, name, or supported class choices when you care about them. Leave any supported choice Random when you do not.

3

Forge and validate

The Forge resolves remaining choices inside its verified source boundary and validates the supported character before it is shown.

4

Save or print

Keep a generated character in the local Pregen library, export a backup when you want one, or print a class-specific Deluxe or Ink Saver packet.

2014 or 2024?

You do not need to mix rules manually. Choose one edition at the start and the Forge follows that selected ruleset for the supported character. This is especially useful when a table wants pregens that all use the same edition.

What does Random mean?

Random is a convenience choice, not permission to invent rules. The Forge selects from its supported, verified options for the selected edition. If a required combination cannot be resolved inside that boundary, the generator is designed to fail closed.

What makes a useful pregen?

A pregen should be fast to understand at the table. Character Forge combines the generated character with attacks, defenses, resources, spells when applicable, and source-aware quick-reference material, then produces printable class-specific sheets.

Good times to use a pregen

  • A one-shot where players need to start quickly.
  • A new player who wants to learn by playing instead of building from scratch.
  • A backup character for a campaign session.
  • A DM who needs several ready-to-play characters for a table or event.
  • A group comparing supported 2014 and 2024 character builds without mixing editions.
